# Captures d'écran du guide d'utilisation

Le guide [GUIDE-UTILISATION.md](../GUIDE-UTILISATION.md) appelle 21 images.
Ce dossier est l'endroit où les déposer. Tant qu'une image manque, le guide
reste lisible : seul un cadre vide apparaît à sa place.

## Comment procéder

Enregistrez chaque image **sous le nom exact indiqué**, au format PNG, dans ce
dossier. Le guide les retrouvera tout seul.

Pour capturer sous Windows : **Windows + Maj + S**, puis sélectionnez la zone et
collez dans un éditeur d'image pour enregistrer. Pour une page longue, la
fonction « Capture d'écran de la page entière » du navigateur donne un meilleur
résultat (dans Chrome : F12, puis Ctrl+Maj+P, taper « capture », choisir
« Capture full size screenshot »).

Deux conseils qui changent le résultat :

- **Fenêtre large**, au moins 1400 pixels : sous cette largeur la colonne de
  navigation disparaît et les filtres se replient sur deux rangées.
- **Ne montrez que ce qui illustre**. Pour un formulaire ou une boîte de
  dialogue, cadrez sur la boîte, pas sur l'écran entier.

> **Avant de diffuser le guide**, regardez ce que les captures montrent : noms,
> adresses e-mail, intitulés de publications non encore parues. Si le guide doit
> circuler hors de l'institution, mieux vaut composer les captures sur des
> données de démonstration.
